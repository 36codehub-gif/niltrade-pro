
# NilTrade Pro

A demo options trading dashboard for NIFTY 50 and SENSEX.

## Features
- NIFTY 50 and SENSEX simulated prices
- Live-style price graph
- EMA 9 and EMA 21 indicators
- RSI indicator
- CALL and PUT demo trading
- Virtual wallet of ₹1,00,000
- Buy and exit positions
- Demo profit and loss calculation

## Technologies
- HTML
- CSS
- JavaScript
- Chart.js

## Disclaimer
This project uses simulated market prices. It does not provide real-time NSE/BSE data or execute real trades. Signals are for educational demonstration only.
